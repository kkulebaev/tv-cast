# tv-cast

Показывает фильмы с ПК на телевизоре через Google Cast (встроенный Chromecast в Google TV / Android TV). На телевизор ничего ставить не нужно.

## Запуск

```sh
cd ~/develop/tv-cast
uv run tvcast
```

Интерфейс: http://localhost:8765. С телефона в той же сети: `http://192.168.3.116:8765`.

Фильмы класть в `~/Видео/Фильмы`, можно с подпапками. Субтитры подхватываются, если файл лежит рядом и называется так же: `Фильм.srt`, `Фильм.ru.srt`.

## Как отдается файл

| Режим | Когда | Нагрузка |
|---|---|---|
| напрямую | MP4/WebM с H.264/HEVC/VP9 и AAC/MP3/Opus | никакой, ТВ сам качает файл с перемоткой |
| пересборка | MKV, звук AC3/DTS/EAC3, выбрана не основная дорожка | видео копируется, звук → AAC |
| перекодирование | H.264 10-bit, MPEG-4/XviD и прочее, или галочка в UI | H.264 через VAAPI на RX 9070 XT |

В режимах пересборки и перекодирования перемотка перезапускает ffmpeg с новой точки.

## Настройки (переменные окружения)

- `TVCAST_MEDIA_DIR` — папка с фильмами (по умолчанию `~/Видео/Фильмы`)
- `TVCAST_PORT` — порт (8765)
- `TVCAST_HOSTS` — IP телевизоров через запятую, опрашиваются помимо mDNS (`192.168.3.4`)
- `TVCAST_VAAPI` — устройство VAAPI (`/dev/dri/renderD128`)

## Ограничения

- Субтитры-картинки (PGS/VobSub из Blu-ray-рипов) не поддерживаются, только текстовые.
- Сервер открыт для всей домашней сети без пароля.
