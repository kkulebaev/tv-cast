# tv-cast

Домашний медиасервер, который отправляет фильмы с ПК на телевизор с Google Cast (Chromecast, Google TV, Android TV). На телевизор ничего ставить не нужно: управление идёт из браузера на ПК или телефоне.

## Возможности

- Находит телевизоры в локальной сети через mDNS и по заданным IP.
- Показывает библиотеку фильмов из папки, включая подпапки.
- Отдаёт файл без обработки, если телевизор умеет его воспроизводить. Иначе пересобирает контейнер или перекодирует на лету через ffmpeg.
- Перекодирует видео на GPU через VAAPI и переводит HDR в SDR.
- Даёт выбрать звуковую дорожку.
- Показывает субтитры: встроенные текстовые и внешние файлы `.srt` / `.vtt`.
- Умеет паузу, перемотку и громкость из веб-интерфейса.
- Запоминает, где остановился просмотр, и отмечает просмотренное. Позиции хранятся на сервере, поэтому фильм, начатый с ПК, можно продолжить с телефона.
- Собирает серии в сериалы и подсказывает, какую серию смотреть дальше.

## Требования

- Linux, Python 3.12+
- [uv](https://docs.astral.sh/uv/)
- `ffmpeg` и `ffprobe` в `PATH`
- Для аппаратного перекодирования: GPU с поддержкой VAAPI (AMD или Intel) и драйверы Mesa
- Для HDR-фильмов: Vulkan-драйвер, чтобы тонмаппинг шёл на GPU через libplacebo. Без него ffmpeg переводит HDR в SDR на процессоре через zscale, а для 4K это может не успевать за воспроизведением
- ПК и телевизор в одной локальной сети

## Запуск

```sh
git clone https://github.com/kkulebaev/tv-cast.git
cd tv-cast
uv run tvcast
```

Интерфейс открывается на http://localhost:8765. С телефона в той же сети: `http://<IP-адрес-ПК>:8765`, этот адрес выводится в консоль при запуске.

Фильмы кладите в `~/Видео/Фильмы` или в папку из `TVCAST_MEDIA_DIR`. Серии узнаются по `S01E04`, `S01x04` или `1x04` в имени файла. Название сериала берётся из имени файла (`The.Witcher.S01E04.mkv`), а если там только номер серии, то из папки (`Ведьмак/Season 1/S01E04.mkv`). Внешние субтитры подхватываются, если файл лежит рядом с фильмом и называется так же: `Фильм.srt`, `Фильм.ru.srt`.

## Настройки

Задаются переменными окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TVCAST_MEDIA_DIR` | `~/Видео/Фильмы` | папка с фильмами |
| `TVCAST_PORT` | `8765` | порт веб-интерфейса |
| `TVCAST_HOSTS` | — | IP телевизоров через запятую. Их опрашивают помимо mDNS, потому что mDNS может не найти телевизор сразу после включения |
| `TVCAST_VAAPI` | `/dev/dri/renderD128` | устройство VAAPI |
| `TVCAST_STATE_DIR` | `~/.local/state/tvcast` | где хранятся позиции просмотра (`progress.json`) |

Пример:

```sh
TVCAST_MEDIA_DIR=/mnt/media/movies TVCAST_HOSTS=192.168.1.50 uv run tvcast
```

## Как отдаётся файл

| Режим | Когда | Нагрузка |
|---|---|---|
| напрямую | MP4/WebM с H.264/HEVC/VP9 и AAC/MP3/Opus | никакой: телевизор сам скачивает файл и перематывает его |
| пересборка | MKV; звук AC3/DTS/EAC3; выбрана не основная дорожка | видео копируется, звук перекодируется в AAC |
| перекодирование | H.264 10-bit, MPEG-4/XviD и прочее, или включена галочка в интерфейсе | видео перекодируется в H.264 через VAAPI, HDR переводится в SDR |

При пересборке и перекодировании перемотка перезапускает ffmpeg с новой точки.

При перекодировании видео декодируется тоже на GPU. Если GPU не умеет декодировать кодек (например, H.264 10-bit или MPEG-4 на AMD), ffmpeg сам переходит на декодирование процессором.

## Ограничения

- Субтитры-картинки (PGS/VobSub из Blu-ray-рипов) не поддерживаются, только текстовые.
- У сервера нет авторизации, он открыт для всей локальной сети. Не открывайте порт в интернет.
